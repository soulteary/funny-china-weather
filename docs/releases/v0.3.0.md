# v0.3.0

This release gives weather icons explicit resource names, adds a complete
offline SVG gallery, and publishes CI-generated coverage and quality reports.
Go 1.27.3 or later remains required. Public function signatures are unchanged.

## Breaking change: icon keys

Old resource names are removed without compatibility aliases. Replace literal
or persisted keys using the [complete naming guide](../icon-names.md).
Examples: `day` becomes `clear-day`, `cloudy` becomes `overcast`, `rainy-4`
becomes `rain-light`, and `icon-sleet` becomes `freezing-rain`.
Day/night pairs and artwork variant names now state their meaning explicitly.
Unknown weather codes return the new `unknown` icon and `未知` description,
including at night, instead of sunny artwork. The embedded set has 34 SVGs;
the original 33 illustrations retain their exact artwork bytes.

Applications that pass `GetWeatherIconByCode` or `GetWeatherIconAt` results
directly to `GetSVGCodeByName` or `GetIconSVG` continue to work without changing
their call sites. This includes Flare's existing weather flow. Restart after
upgrading to clear in-memory old keys; migrate any externally persisted keys.

## Added

- A self-contained [SVG gallery](../icon-preview.html) for all 34 resources,
  labeling names, conditions, codes and automatic-match status. Search, filter,
  light/dark canvases, size controls, CSS/SMIL pause and actual static SVG output
  aid manual inspection. Regenerate with `go run ./examples/icon-preview`.
- Go Test Report Action and Go Report Card Action, pinned to release commits,
  with repository-local README badges and reports. Tests run with race detection
  and atomic coverage. PRs retain read-only permissions; default-branch writeback
  publishes five stable files only when the branch still matches tested source.
- Canonical-resource inventory and removed-key tests, selector-to-SVG checks,
  gallery composition tests and a reusable Flare-side compatibility fixture.

## Validation and limits

Project tests, race detection, vet, workflow validation and cross-platform
builds passed. An isolated Flare checkout passed its full tests, weather/home
race tests and a 38-code actual consumer/template check. The gallery's inline
SVG XML, references and unique IDs were checked. Browser animation inspection
remains manual; these checks do not claim a browser animation pass.

IPIP and Tencent remain external services. Previously observed intermittent
IPIP EOF failures are not resolved or masked by this release.

## Upgrade

```sh
go get github.com/soulteary/funny-china-weather@v0.3.0
```

The Go module path and the exported Go API signatures are unchanged. Only
resource keys and the unknown-condition artwork intentionally break old
name-based assumptions. Existing BSD and upstream MIT notices are retained;
the new unknown icon is original artwork under the project BSD license.
