# 晴雨笺 v0.4.0

This release adds provider-backed location selection, expands the icon set to
49 SVG resources, and reduces repeated SVG parsing and Flare cache contention.
Requires Go 1.27.3 or later. The Go module path remains unchanged.

## Upgrade and location-input migration

```sh
go get github.com/soulteary/funny-china-weather@v0.4.0
```

String weather APIs now accept a Tencent search keyword, such as `北京`, or
the comma-separated address produced by `Location.String()`. Replace old
concatenated addresses: local province aliases, suffix inference and Chinese
address parsing have been removed. Missing or ambiguous search results return
`ErrLocationNotFound` or `ErrAmbiguousLocation`; no candidate is chosen silently.

Prefer `SearchLocations` during configuration, let the user select a candidate,
then retain its `Location` and call `GetObservationAt` for refreshes. This keeps
Tencent's province/city/county fields and supports districts and county-level
cities without repeated directory lookups. IP location resolution now searches
Tencent with IPIP's city name and requires an exact province match.

Existing exported function signatures remain available. IP location strings
now contain provider fields, such as `浙江, 杭州`, without inferred suffixes.
See the [README](../../README.en.md) for complete examples.

## Icons

- Add 15 animated resources for fog/haze intensities, blowing sand, sandstorms,
  rainstorms and snowstorms; all v0.3.0 resource keys remain available.
- Recognize codes 49 and 54–58 and select more specific artwork for existing
  intensity codes. Keep returned descriptions to distinguish ranges that
  share an icon. Resource support does not guarantee live-provider coverage.
- Expand the offline gallery to all 49 resources: 38 automatically selected
  resources, including `unknown`, and 11 manual variants.

See the [icon guide](../icon-names.md) for mappings and v0.2.0 key migration.

## Performance and examples

Animated and static SVG templates are compiled lazily and reused. Each render
still applies its own instance prefix, preserving inline SVG isolation.

The Flare example coalesces refreshes per location without holding the global
map mutex during network requests or rendering. Waiting callers can cancel.
The cache holds at most 128 entries, evicts entries idle for one hour on access,
and retains its ten-minute refresh and one-minute failure retry policy.
`Cache.GetAt` fetches a selected location without a directory lookup.

The project now uses the Chinese name 晴雨笺, with Chinese and English READMEs.
BSD and upstream MIT license notices remain unchanged.
