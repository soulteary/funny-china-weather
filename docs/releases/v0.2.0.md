# v0.2.0

This release improves weather correctness, request handling and inline SVG
composition while keeping the four functions published in v0.1.1 available.
It requires **Go 1.27.3 or later**.

## Upgrade from v0.1.1

```sh
go get github.com/soulteary/funny-china-weather@v0.2.0
```

The module path is unchanged. This command resolves after the v0.2.0 tag has
been published; the publication gates are tracked in the
[release checklist](https://github.com/soulteary/funny-china-weather/blob/v0.2.0/docs/releases/v0.2.0-checklist.md).

- **Toolchain:** the minimum Go version rises from Go 1.17 to Go 1.27.3.
- **Existing functions:** `GetMyIPLocation`, `GetWeatherByLocation`,
  `GetWeatherIconByCode`, and `GetSVGCodeByName` retain their signatures.
  `GetSVGCodeByName` is deprecated in favor of `GetIconSVG` and still returns
  trusted bundled SVG as `html/template.HTML`.
- **Observation validation:** HTTP/business failures, incomplete observations,
  invalid integer fields and humidity outside 0–100 now return errors rather
  than partial or zero-valued success. Check errors before reading results.
  Exact error strings are not a compatibility contract; inspect `Error` with
  `errors.As` and underlying causes with `errors.Is`.
- **Update time:** the tuple API now returns Tencent's actual `update_time`;
  v0.1.1 returned an empty string. Fetching preserves the raw nonblank value
  and does not automatically validate its date or enforce freshness.
- **Weather labels:** corrected descriptions and icon choices can change UI
  text, stored snapshots or assertions. Unknown codes, including `-1`, use
  `day` / `未知`. Daytime is 05:00 inclusive to 19:00 exclusive in the selected
  time's zone.
- **SVG bytes and selectors:** generated IDs, classes and animation names are
  isolated per instance, so returned bytes and internal selectors change.
  Use `GetIconSVGWithPrefix` for reproducible output and allocate a unique
  prefix to each inline DOM slot. A cache key must include both icon and slot
  prefix; do not duplicate a cached final SVG string across inline positions.

## Added

- A Flare-style consumer example with ten-minute cache refresh, one-minute
  failure retry spacing, stale-data indicators and isolated SVG instances.
  Deterministic tests and opt-in real-provider tests cover cache refresh and
  the automatic IP-location-to-weather flow. Browser animation verification
  remains a follow-up; it is not asserted by these tests.
- `GetMyIPLocationContext` and `GetWeatherByLocationContext` for caller
  cancellation with the existing three-second client timeout.
- `GetObservation` and `Observation` preserving provider descriptions,
  temperature, humidity, weather code and raw update time.
- `ParseUpdateTime` for strict `YYYYMMDDHHMM` parsing in UTC+8, and
  `Observation.Age` / `IsStale` for caller-selected freshness checks.
  Parsing rejects malformed input and invalid calendar dates; `Age` and
  `IsStale` also reject timestamps after the supplied reference time. Fetching
  an observation still preserves the raw value. A nonpositive staleness
  threshold is rejected, and age equal to the threshold is not stale.
- `Error` metadata for provider, stage, HTTP/business status and field, while
  retaining wrapped request, context and parsing causes. `ErrResponseTooLarge`
  identifies the response-size limit.
- `GetWeatherIconAt`, `GetIconSVG`, `GetIconSVGWithPrefix`, and
  `GetStaticIconSVG`. Static SVGs disable CSS and SMIL animation while retaining
  precipitation; the application chooses this variant based on its users'
  motion preferences.

## Correctness and packaging

- Correct thunderstorm/hail, freezing rain, dust, visibility and rain/snow
  intensity descriptions. Support legend codes 53, 301 and 302; legend support
  does not imply Tencent's observation endpoint emits all of them.
- Normalize municipalities, autonomous regions and explicit prefecture/league
  aliases. Accept legitimate names such as 津市市, and reject municipality
  mismatches, repeated levels, malformed UTF-8 and invisible format characters.
- Bound responses to 1 MiB, check HTTP and provider status, and require a single
  valid JSON value while accepting unknown fields.
- Correct 28 `viewBox` attributes, isolate SVG references/CSS across instances
  and processes, and restore missing sleet animation references.
- Embed all 33 SVGs and remove the former minifier/parser dependencies. There
  are no third-party Go module dependencies or required asset-generation steps.

## Usage limits

Location normalization is not a complete administrative-division database and
does not establish provider coverage. IPIP and Tencent availability and data
freshness remain upstream concerns; requests do not retry automatically.
`GetWeatherIconByCode` uses the process's local time; use `GetWeatherIconAt` for
an explicit time and zone.

SVG output is intended for the bundled trusted resources. Every generation
still parses and rewrites the asset; a fixed prefix provides deterministic
output, not a computation cache. Measure high-density server rendering before
choosing a caching strategy that preserves instance isolation.
