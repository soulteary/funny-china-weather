白天为 05:00（含）至 19:00（不含）。备用资源的数字只表示构图变体。雾与霾、不同强度降雨等可能共用图标，具体天气以文字为准。unknown 是未知代码的自动兜底。

“暂停动画”同时控制 CSS 动画与浏览器支持的 SVG SMIL 动画；“静态版本”展示 GetStaticIconSVG 的真实输出。系统启用减少动态效果时，默认暂停。查看动画需要点击“继续动画”。unknown 本身没有动画。

来源：当前工作区 icons/*.svg 与 GetWeatherIconAt 的昼夜映射。本页用于人工检查显示效果，不代表已经通过浏览器动画验证。
